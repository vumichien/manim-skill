# Voiceover Setup

When `--voice` is passed, the implementer wraps each scene in a `manim_voiceover.VoiceoverScene` with the chosen TTS provider. This doc lists the env-var setup users need before they invoke `--voice`.

## Provider matrix

| Provider | Cost | Quality | Setup |
|---|---|---|---|
| `gtts` (Google TTS) | free | acceptable | none |
| `openai` | paid | very good | `OPENAI_API_KEY` |
| `elevenlabs` | paid | best | `ELEVENLABS_API_KEY` |

`manim-voiceover` also supports `azure` and a local `Recorder`, but they are not exposed via `--voice` in v0.1 (they need extra setup). Users can author scenes that use them directly.

## Default and fallback

- `--voice` (no value) → `gtts`
- `--voice gtts` → `gtts`
- `--voice openai` → `openai`. If `OPENAI_API_KEY` is missing, the skill falls back to `gtts` and prints a warning in `summary.md`.
- `--voice elevenlabs` → `elevenlabs`. Same fallback rule.

The fallback policy is encoded in the implementer agent prompt (`agents/manim-implementer.md`).

## Env-var setup

### gTTS

Nothing to do. The package uses Google's free unauthenticated endpoint. Rate-limited; for >50 requests/hour, switch to a paid provider.

### OpenAI

```bash
# Linux/macOS
export OPENAI_API_KEY="sk-..."

# Windows PowerShell (current session)
$env:OPENAI_API_KEY = "sk-..."

# Windows PowerShell (persistent)
[Environment]::SetEnvironmentVariable("OPENAI_API_KEY", "sk-...", "User")
```

Voice options used by default: `voice="fable"`, `model="tts-1-hd"`. Override in `agents/manim-implementer.md` if needed.

### ElevenLabs

```bash
export ELEVENLABS_API_KEY="..."
```

Default voice: `voice_name="Adam"`, `voice_settings={"stability": 0.5}`. Override per scene via `meta.notes` in the storyboard if needed.

## Authoring pattern

The implementer emits scenes like this when voice is enabled:

```python
from manim import *
from manim_voiceover import VoiceoverScene
from manim_voiceover.services.gtts import GTTSService

class Scene01(VoiceoverScene):
    def construct(self):
        self.set_speech_service(GTTSService(lang="en"))
        with self.voiceover(text="A right triangle appears.") as t:
            self.play(Create(triangle), run_time=t.duration)
```

Provider swap (autogenerated based on `--voice`):

```python
from manim_voiceover.services.openai import OpenAIService
self.set_speech_service(OpenAIService(voice="fable", model="tts-1-hd"))
```

```python
from manim_voiceover.services.elevenlabs import ElevenLabsService
self.set_speech_service(ElevenLabsService(voice_name="Adam"))
```

## Per-scene narration text

The planner agent fills `scenes[].voiceover_text` based on the beat and target duration. Keep it short — TTS speaking rate is roughly 150 words/minute, so a 10-second scene needs ≤25 words.

If a scene's `voiceover_text` is `null` (e.g. visual-only intro/outro), the implementer emits the scene without a voiceover wrapper, even when `--voice` is set globally.

## Cost guardrails

- OpenAI tts-1-hd: $0.030 / 1k characters. A 5-minute video at 150 wpm ≈ ~750 words ≈ ~4500 chars ≈ $0.14 per render.
- ElevenLabs Starter: 30k chars/month included; the same 5-min video uses ~15% of the monthly quota.
- gTTS: free; no per-request billing.

`summary.md` reports the total character count sent to TTS so users can audit cost.

## Security

- API keys are read from env vars at run time. The skill never writes them to disk.
- `.env` is in `.gitignore`. Users are warned in the README never to commit it.
- If a key is missing for a paid provider, the skill warns and falls back; it never silently rejects without TTS.
